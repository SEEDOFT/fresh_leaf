# FreshLeaf

FreshLeaf is a Flutter + GetX organic grocery app with:
- Authentication
- Home/product browsing
- Cart + checkout
- Orders + order details
- Profile (personal, security, addresses)
- PIN security for order access
- AI assistant chat

## Documentation

See:
- `documentations/development_summary.md` (full app outline and architecture)

## Run

Use your VS Code launch config or run with define file:

```bash
flutter run --dart-define-from-file=.env.local
```
